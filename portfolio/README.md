# Portfolio Projects

This directory contains completed, reproducible portfolio projects that support the profile focus on AI evaluation, data quality, Python automation, and business-data research.

| Project | Focus |
|---|---|
| [Data Quality & Validation](./data-quality-validation/) | Dataset profiling and validation |
| [Python API Automation](./python-api-automation/) | JSON API ingestion and normalization |
| [Business Data Research](./business-data-research/) | Research preparation, deduplication, and summary |

All example datasets are synthetic. The projects demonstrate workflow design and engineering practices without representing private client work or unverifiable professional experience.
